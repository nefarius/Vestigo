Vestigo

A Windows MCP server for driver and application development.

Vestigo runs as a Windows service and exposes tools for WPP and ETW tracing, bounded presentation observation, devices, drivers, and read-only HID capabilities, processes, services and scheduled tasks, files, JSON document queries, windows and window-event capture, gated window placement, gated display-layout changes, a virtual-display backend that is not yet available, gated managed test desktops, foreground and cursor inspection, screenshots with an optional short-lived preview link, and screen inspection with gated mouse and keyboard input, audio, system, UAC, boot state, boot security, logon sessions, power state, and the last wake source, debug output, PE inspection, loaded modules, SetupAPI install history, device problem codes, driver load evidence, graphics adapters, gated capture probes, process connections, gated DNS, TCP, TLS, and UDP probes, Media Foundation encoders and camera formats, gated audio playback probes, Windows Error Reporting metadata, kernel dump metadata, Driver Verifier state, gated process dumps, gated Windows Firewall profile and rule inventory, event logs, opt-in read-only Windows Update and servicing diagnostics, opt-in allow-listed registry reads, and signed self-update.

This is not a browser UI

Use Vestigo through an AI agent or MCP client such as Cursor, Claude, or Visual Studio Code over Streamable HTTP. This page only explains how to connect.

Connect an agent

Point the client at the Streamable HTTP endpoint:

<origin>/mcp

Example client configuration:

{
  "mcpServers": {
    "vestigo": {
      "url": "http://HOST:5098/mcp",
      "headers": {
        "Authorization": "Bearer <token>"
      }
    }
  }
}

Bearer tokens sent over plain HTTP are visible on the network. If you connect remotely, use a trusted network or a TLS-terminating proxy.

Authentication

When ApiTokens is configured, send Authorization: Bearer <token>. After an MSI install the token is in %ProgramData%\Nefarius Software Solutions\Vestigo\appsettings.json. /health is available for probes and stays anonymous. File-transfer URLs returned by tools carry a one-time ?ticket= so clients do not need the token for /files.
